# CodeAlpha Hangman Game

## Description
A simple text-based Hangman game developed using Python as part of the CodeAlpha Internship.

## Features
- Randomly selects a word from a predefined list
- Allows the player to guess one letter at a time
- Displays correctly guessed letters
- Allows a maximum of 6 incorrect guesses
- Detects repeated guesses
- Displays win or game-over messages

## Technologies Used
- Python
- Random module

## How to Run
Run the following command:

python hangman.py

## Game Rules
- Guess the hidden word one letter at a time.
- Each incorrect guess reduces the remaining attempts.
- The player gets a maximum of 6 incorrect guesses.
- Guess all the letters correctly to win the game.
